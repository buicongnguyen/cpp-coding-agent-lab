# Recorded deterministic demonstrations

Last verified: 2026-08-08

These JSONL files are generated by the tested reference executable and serve as network-free classroom fallbacks:

- `full_repair_trace.jsonl` — complete discovery, compile failure, minimal repair, behavioral test failure, second repair, and passing verification.
- `repeated_read_trace.jsonl` — repeated identical-call limit terminating a pathological loop.

Regenerate after implementation or fixture changes. Copy `fixture/buggy_calculator` into a fresh disposable directory before the full-repair run, then pass `--trace <path>`. Trace content can include source and compiler output; use only synthetic teaching repositories and never put credentials in recorded demos.

The CLI replaces the selected workspace root with `<WORKSPACE>` in emitted trace details so recorded demonstrations remain portable. Each event includes elapsed milliseconds; model-request events record context/tool counts, while model-response and tool events preserve the normalized protocol evidence used in the lesson.
