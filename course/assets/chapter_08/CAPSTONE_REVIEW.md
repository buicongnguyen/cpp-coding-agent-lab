# Capstone review and failure retrospective

## Success ladder

- [ ] L1: correct files identified and plausible plan.
- [ ] L2: coherent, focused diff.
- [ ] L3: modified source compiles.
- [ ] L4: existing tests pass after latest write.
- [ ] L5: new normal, escape, and output-limit tests pass.
- [ ] L6: final report accurately cites diff/build/test evidence and limits.

## Failure classification

For each observed failure choose one: missing/stale context, ambiguous prompt, weak schema, dispatcher/policy, generated C++, loop/stop policy, false report, incomplete evaluation, or infrastructure. Cite the event and choose keep/amend/discard.

Final reviewer statement: Which claims are proven, which remain unproven, and what is the smallest next action?
